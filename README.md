# スクショレシピ帳（オフライン版）

インスタやクックパッドのスクショを保存して、材料・手順・改善メモを残す自分用レシピ帳です。
GitHub Pages で公開して iPhone のホーム画面に追加すると、電波がなくても使えます。

- レシピと写真はその端末の中（ホーム画面のアプリ）だけに保存されます。
- 右上の「…」から、バックアップの書き出し・読み込みができます。

## アプリを更新するとき
ファイルを差し替えたら、`sw.js` の `const VERSION = "v1";` の数字を上げてください（v2, v3…）。
次に開いたときに新しい版に切り替わります（反映まで2回ほど開き直しが必要なことがあります）。
